# S4-02_ApplicationRepartie


## Setup Projet :
- Créer la classe `src/Credentials.java`, avec le code suivant à compléter :
```java
public class Credentials {
    public static final String USERNAME = "", PASSWORD = "";
}
```

- En fonction de votre IDE, importer les librairies `lib/ojdbc11.jar` et `lib/json-20131018.jar`.
